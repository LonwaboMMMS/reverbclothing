# Reverb Clothing\n\nInitial frontend for a clothing e-commerce app.\n\n## Current scaffold\n- Responsive clothing storefront and product cards\n- Filters by product type, colour, and size; sorting by price\n- Hex colour swatches and manually configured product colours\n- Size selection and stock-count fields in demo product manager\n- Account UI: login, signup, forgot-password flow placeholder\n- Cart UI and checkout placeholder\n- Floating, rounded liquid-glass mobile navigation\n- Local browser storage for demo products (not shared/server persistence)\n\n## Important\nThis is a frontend prototype. Authentication, secure account storage, order tracking, address management, password reset email delivery, image uploads, inventory persistence, checkout, payment, and admin authorization require backend services. Do not deploy as a live store or collect real passwords until these services are implemented.\n\nOpen `index.html` to preview locally or deploy as static Pages.\n
